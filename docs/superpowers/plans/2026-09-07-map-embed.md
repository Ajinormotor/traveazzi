# Google Maps Embed Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the static map PNG backgrounds on all 19 screens with a live Google Maps embed (directions on ride screens, area view elsewhere), staying on Expo Go.

**Architecture:** One new component (`components/MapEmbed.tsx`) wraps `react-native-webview` (13.16.1, already installed and bundled in Expo Go — no native changes). Each screen keeps its layout and only swaps the `ImageBackground` wrapper for a plain `View` with `MapEmbed` absolute-filled behind the unchanged children. Key comes from `process.env.EXPO_PUBLIC_GOOGLE_MAPS_KEY`; missing key, load failure, offline, or empty address leg all render the screen's current static image.

**Tech Stack:** Expo SDK 57, React Native 0.86, react-native-webview 13.16.1, Google Maps Embed API v1, twrnc, TypeScript strict.

## Global Constraints

- Must keep working in Expo Go (SDK 57) — no native modules, no config plugins, no `ios/`/`android/` dirs.
- No test suite exists in this repo (`npx jest --passWithNoTests` exits 0) — verification per task is `npx tsc --noEmit`, `npx expo-doctor@latest`, and `npx expo export -p web`; final visual check is human-side in Expo Go.
- Never build a directions URL with an empty origin or destination — fall back to area view.
- `encodeURIComponent` every user-supplied value placed in the embed URL.
- Do not touch booking payloads and do not "fix" the `pickupAddress`/`dropoffAddress` swap in `(passenger)/confirmRide` — out of scope.
- Default center is Port Harcourt `{ lat: 4.8156, lng: 7.0498 }`, default zoom 13.
- Follow the existing `EXPO_PUBLIC_*` env pattern (`store/authStore.tsx:6`).

- [ ] **Step 1: Create `components/MapEmbed.tsx` with this exact content**

```tsx
import React, { useState } from 'react';
import { Image, ImageSourcePropType, StyleSheet, View } from 'react-native';
import { WebView } from 'react-native-webview';

const MAPS_KEY = process.env.EXPO_PUBLIC_GOOGLE_MAPS_KEY ?? '';
const DEFAULT_CENTER = { lat: 4.8156, lng: 7.0498 }; // Port Harcourt
const DEFAULT_ZOOM = 13;

export type MapEmbedProps = {
  mode: 'view' | 'directions';
  center?: { lat: number; lng: number };
  zoom?: number;
  origin?: string;
  destination?: string;
  fallback: ImageSourcePropType;
};

function buildUrl(props: MapEmbedProps): string | null {
  if (!MAPS_KEY) return null;
  if (props.mode === 'directions') {
    const origin = props.origin?.trim() ?? '';
    const destination = props.destination?.trim() ?? '';
    if (origin && destination) {
      return `https://www.google.com/maps/embed/v1/directions?key=${MAPS_KEY}&origin=${encodeURIComponent(origin)}&destination=${encodeURIComponent(destination)}`;
    }
    // empty leg: fall through to area view
  }
  const c = props.center ?? DEFAULT_CENTER;
  const z = props.zoom ?? DEFAULT_ZOOM;
  return `https://www.google.com/maps/embed/v1/view?key=${MAPS_KEY}&center=${c.lat},${c.lng}&zoom=${z}`;
}

export default function MapEmbed(props: MapEmbedProps) {
  const [failed, setFailed] = useState(false);
  const url = buildUrl(props);
  if (!url || failed) {
    return <Image source={props.fallback} style={StyleSheet.absoluteFill} resizeMode="cover" />;
  }
  return (
    <View style={StyleSheet.absoluteFill}>
      <WebView
        source={{ uri: url }}
        style={{ flex: 1 }}
        javaScriptEnabled
        domStorageEnabled
        onError={() => setFailed(true)}
        onHttpError={() => setFailed(true)}
      />
    </View>
  );
}
```
